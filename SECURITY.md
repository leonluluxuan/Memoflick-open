# Security

Please do not publish secrets, private user data, or unpatched vulnerability
details in a public issue. Use GitHub's private vulnerability reporting form
for this repository when available:

<https://github.com/leonluluxuan/Memoflick-open/security/advisories/new>

If the form is unavailable, contact the maintainer privately through GitHub
before disclosure.

Security reports should include the affected version, device and OS version,
reproduction steps, and the potential impact. Relevant areas include
unexpected media uploads, local storage and App Group access, deletion and
recovery behavior, and sensitive data exposed to the widget. Please redact
private photos, identifiers, credentials, and other personal information.
