# Security / 安全报告

## English

Please do not publish secrets, private user data, or unpatched vulnerability
details in a public issue. Use GitHub's private vulnerability reporting form
when available:

<https://github.com/leonluluxuan/Memoflick-open/security/advisories/new>

If the form is unavailable, contact the maintainer privately through GitHub
before disclosure.

Security reports should include the affected version, device and OS version,
reproduction steps, and potential impact. Relevant areas include unexpected
media uploads, local storage and App Group access, deletion and recovery
behavior, and sensitive data exposed to the widget. Redact private photos,
identifiers, credentials, and other personal information.

## 中文

请不要在公开 Issue 中发布密钥、私人用户数据或尚未修复的漏洞细节。若可用，请使用 GitHub 私密漏洞报告：

<https://github.com/leonluluxuan/Memoflick-open/security/advisories/new>

如果该表单不可用，请先通过 GitHub 私下联系维护者，再进行披露。

安全报告应包含受影响的版本、设备与系统版本、复现步骤和潜在影响。重点范围包括意外媒体上传、本地存储与 App Group 访问、删除与恢复逻辑，以及小组件暴露的敏感数据。请脱敏私人照片、标识符、凭据和其他个人信息。
