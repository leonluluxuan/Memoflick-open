# Code of Conduct / 行为准则

## English

We want this project to be useful, welcoming, and safe for everyone. Treat
other contributors with respect, assume good faith, and focus criticism on
ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, sexualized comments, doxxing, publishing private information, and
deliberate disruption of the project.

Please report a concern privately to the maintainer before discussing
sensitive details in a public issue. Reports should include the relevant link
or context and, when possible, dates and the people involved. The maintainer
may remove content, restrict participation, or close contributions that
violate this standard.

## 中文

我们希望本项目对所有人都实用、友好且安全。请尊重其他贡献者，善意理解不同意见，并针对想法和代码提出批评，不针对个人。

不可接受的行为包括骚扰、歧视、威胁、人身攻击、性化言论、人肉搜索、公开私人信息，以及故意扰乱项目秩序。

涉及敏感内容时，请先私下联系维护者，不要直接发布到公开 Issue。报告请尽量提供相关链接、上下文、时间和涉及人员。对于违反行为准则的内容，维护者可以删除内容、限制参与权限或关闭贡献。
