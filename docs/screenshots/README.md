# Screenshot slots / 截图占位目录

This directory is intentionally reserved for tutorial screenshots. The
repository currently contains no user photos or product screenshots.

此目录专门预留给操作教程截图。当前仓库不包含用户照片或产品操作截图。

## Suggested files / 建议文件

- `01-build-and-sign.png` / 构建与签名
- `02-photo-permission.png` / 照片权限
- `03-review-photos.png` / 整理照片
- `04-review-videos.png` / 整理视频
- `05-favorites-and-memories.png` / 收藏与回忆
- `06-trash-and-recovery.png` / 垃圾箱与恢复
- `07-home-screen-widget.png` / 桌面小组件

Before committing a screenshot, remove personal media, names, Apple IDs,
device identifiers, notifications, and any other private information.

提交截图前，请移除私人媒体、姓名、Apple ID、设备标识、通知内容及其他隐私信息。
