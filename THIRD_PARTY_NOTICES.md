# Third-party notices

The formal Xcode project currently has no Swift Package Manager, CocoaPods,
or Carthage runtime dependency in this staging snapshot. It uses Apple SDKs,
which remain subject to Apple's terms.

## Bundled visual assets

The source tree includes app icons, Memoflick logos, and photo-wall background
images under `memoflick/memoflick/Assets.xcassets`. These assets are not
automatically covered by the source-code license. Their original ownership or
redistribution terms are not encoded in the Xcode project, so forks and
redistributors must either obtain permission or replace them before shipping
an app or redistributing the assets.

No third-party font, sound, Swift Package Manager package, CocoaPods package,
or Carthage dependency is declared by this snapshot.
